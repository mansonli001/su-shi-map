  # 3.1 路线基础信息
  route_id: R08
  route_title: 自密州调任徐州知州
  route_period: 1076-1078
  route_age_range: 40岁-41岁
  route_color: "#4682B4"
  route_position: 苏轼自密州奉诏改任河中、再改命徐州的曲折宦游线；走北线**齐鲁→京师近郊→汴河东下**全程；途中**滞留齐州月余、澶濮与苏辙七年重逢、陈桥驿接改命徐州诏**三大核心史实节点；至徐州后临危抗洪筑黄楼、云龙山寄情怀古，是苏轼仕途家国担当与兄弟手足重逢双重交织的关键路线
  # 3.2 时间区间描述
  time_range:
    start: 1076年12月 密州知州任满，奉诏改知河中府启程
    end: 1078年 徐州任内抗洪治水、营建黄楼、遍历境内名胜驻留履职
    description: |
      熙宁九年（1076）十二月，苏轼密州两年知州任期届满，初奉诏改知河中府（今山西永济），
      然辞密州西行至**齐州（济南）滞留月余**，与故友李公择同游龙洞、趵突泉，作《济南龙洞山记》《趵突泉》等纪游诗文；
      熙宁十年（1077）二月，苏轼自齐州继续西行经郓州，**于澶州、濮州一带与弟苏辙七年重逢**，
      苏辙时任著作佐郎、签书南京（应天府）判官，自京师汴梁出发东行迎兄；
      兄弟同行至**京师近郊陈桥驿，恰接朝廷改命知徐州诏书，"不得入国门"**，
      乃寓居京东郊范镇东园待命，旋即沿汴河东下，途经**宿州**作《宿州次韵刘泾》，
      四月二十一日抵达徐州赴任，在任期间临黄河决口、率众抗洪保城，
      事后修筑黄楼纪功，闲暇登临云龙山、百步洪、泗水亭，交友览胜、撰文抒怀。
  # 3.3 整体核心评述
  core_essence: |
    本条路线是苏轼仕途与亲情双重交织的特殊宦游——
    与其他奉旨直达任所的调任路线不同，此次充满**"路途改命"的曲折戏剧性**：
    自密州罢任先得河中府之命，齐州滞留月余、澶濮与子由重逢、陈桥驿再接改徐州诏，
    一路走来非简单赴任，而是**三度命运转折、兄弟七年再聚、北宋朝廷调度变迁**的浓缩缩影。
    至徐州又恰逢黄河决口大水，亲守城门、抗洪安民，尽显士大夫责任担当；
    治水之后营建黄楼、放鹤交友、登临山水，于政务与闲游之间，
    文风兼具沉厚现实关怀与山林隐逸之趣，人格格局愈发沉稳厚重。
