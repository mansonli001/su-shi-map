# 苏轼行踪地图 · 路线手写模板（带说明 · 带眉山示例）

> **谁用**：外部协作者 / 自己手写时参照
> **怎么用**：每条路线一个 `.md` 文件，文件名 `R{编号}_{路线主题}.md`（例：`R00_眉山故里.md`）
> **写完交回**：AI 负责①坐标拾取 ②历史事实校验（李常生《苏轼行踪考》+ 网搜交叉）③图片映射（下一轮）④转 JSON 入库
>
> **铁律**：
> 1. 不会的字段空着，**不要编**——编了我考证不出来比空着还糟
> 2. 时间不确定的写"约 XXXX 年"，AI 会去查
> 3. 「苏轼关联事迹」是地图的灵魂，必须每个点都写
> 4. 点位数**不限**，以完整覆盖苏轼在该路线的全部行踪为准——宁多勿漏

---

## 一、文件整体结构（两层）

```
路线层（route_overview）           ← 整条路线的"首页简介"，地图 Hero / 路线卡片用
   └─ 点位层（places[]）             ← 具体地点，地图标记 + PlaceCard 用
       ├─ 主线点位 (layer: main)
       ├─ 沿途水景 (layer: water)
       └─ 驻留周边 (layer: surrounding)
```

# 第一层 · 路线总览字段（route_overview）

> 你写的眉山版那段「路线总览·首页简介」我把它拆成 **6 个子栏**，外部按子栏填。

## 字段 1.1 路线基础信息（必填）

| 字段 | 含义 | 示例 |
|---|---|---|
| `route_id` | 路线编号，两位数 | `R00` |
| `route_title` | 路线主标题，6-12 字 | `眉山故里·少年成长` |
| `route_period` | 时间区间，纯数字 | `1037-1056` |
| `route_age_range` | 苏轼年龄区间 | `0岁-21岁` |
| `route_color` | 主题色（参考下方色板）| `#7B9E89`（山水青） |
| `route_position` | 在 20 条里的定位（一句话）| `全20条中最本源、最具奠基意义的核心路线` |

**色板参考**（按时期建议）：
- 少年期：`#7B9E89` 山水青
- 应试 / 早期任职：`#8B6914` 赭金
- 黄州 / 惠州 / 儋州 三贬：`#C41E24` 朱砂
- 中期任职：`#4A6670` 远山黛
- 晚年终老：`#A0826D` 老木褐

# 第二层 · 点位字段（places[]）

> **点位数量不限**，以完整覆盖苏轼在该路线的全部行踪为准，按下面三层分类，每个点字段一致

## 点位三层分类（写之前先想清楚）

| layer | 视觉 | 选什么进来 |
|---|---|---|
| `main` 主线 | 地图大墨点（实心朱砂）| 苏轼**必去**的核心点位（住过/任职过/重大事件发生地） |
| `water` 水景 | 中墨点（青色描边）| 沿途江河湖渡口（写过诗 / 反复经过 / 有名意象） |
| `surrounding` 周边 | 小墨点（灰色虚框）| 驻地辐射的访友 / 访寺 / 访道点（短暂停留但有事迹） |

> **原则**：main ≥ water ≥ surrounding 的数量。一条路线 main 一般 4-7 个，water 1-3 个，surrounding 1-3 个。

  related_works:
    - title: 初发嘉州
      type: poem                # poem 诗 / ci 词 / fu 赋 / wen 文
      excerpt: null             # 名句节选，1-2 句
      note: 终生回望眉山故里

  # ========== AI 自动填，外部不用管 ==========

## 字段 2.2 标签库 `tags[]`（复合多选）

| 标签 | 含义 | 用法举例 |
|---|---|---|
| `birth` | 出生 | 眉山故居 |
| `die` | 长眠 | 常州、郏县 |
| `stay` | 长期驻留 | 黄州临皋亭、东坡雪堂 |
| `study` | 治学 / 游学 / 读书 | 三苏祠、中岩寺 |
| `official` | 任官 | 凤翔签判、徐州知州、密州知州 |
| `exile` | 贬谪 | 黄州、惠州、儋州 |
| `visit` | 短暂游览 | 蟆颐山、青神 |
| `friend` | 访友 / 见挚友 | 见王巩、见佛印、见黄庭坚 |
| `poetry` | 重要诗词诞生地 | 赤壁、惠州西湖 |
| `main` | 路线主线节点 | （和 layer:main 配套） |
| `hub` | 水陆枢纽 / 中转 | 彭山江口、瓜洲渡 |

> **复合用法**：眉山故居 = `[birth, stay, study]`；黄州赤壁 = `[exile, poetry, visit]`；徐州 = `[official, stay]`
