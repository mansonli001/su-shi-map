# R06_外放杭州通判·南下江南（1071–1074）
route_overview:
  # 3.1 路线基础信息
  route_id: R06
  route_title: 外放杭州通判·南下江南
  route_period: 1071–1074
  route_age_range: 34岁–37岁
  route_color: "#729E77"
  route_position: 新旧党争避祸自请外放，首次踏入江南水乡；赴任途中**颍州拜别恩师欧阳修**，为二人此生最后相会，三年杭州为官、山水诗创作爆发的人生高光路线

  # 3.2 时间区间描述
  time_range:
    start: 1071年 苏轼因反对王安石新法，自请外放，从汴京南下启程
    end: 1074年 杭州通判任满，结束三年江南仕宦与山水游历生涯
    description: |
      熙宁四年，苏轼在汴京朝堂与新法政见不合，为避党争倾轧，主动请求外任。
      循中原江淮古驿道一路南行，经陈州抵达颍州，**专程拜谒致仕归隐的文坛宗师欧阳修**，
      师生泛舟论道、话别经年，亦为二人此生最后一面。
      随后经寿州、庐州、滁州抵长江北岸，由瓜州渡江进入江南，沿运河经润州、常州、苏州抵达杭州。
      履职三年间，分管州务、刑狱、漕运，勤政宽和，浚治六井惠民；
      遍历西湖及江南名山大刹，与诗僧文士交游唱和，诗文词全面鼎盛。

  # 3.3 整体核心评述
  core_essence: |
    本条是苏轼**离开朝堂漩涡、转向江南山水人生的分水岭**。
    南下途中颍州拜见欧阳修，师生永诀，奠定其文章道义、立身行事的终身准则。
    告别汴京政治纷争，一路由中原入江淮、渡江进江南，
    风物从北方平原转为温婉水乡，心境由朝堂忧愤转为闲适旷达。
    杭州三年，官事清简、民风尚雅，理政不苛、体恤百姓，
    深耕西湖山水、访古寻幽，文学天赋全面绽放，
    既是仕途避祸缓冲期，也是师生文脉传承、山水文学巅峰的黄金岁月。

  # 3.5 核心游历地点总括
  key_locations_summary: |
    完整官方行进：汴京→陈州→**颍州（拜欧阳修）**→寿州→庐州→滁州→扬州→瓜州渡→润州→常州→苏州→杭州
    沿途游览：颍州西湖（欧苏相会地）、滁州琅琊山、镇江金山寺、姑苏寒山寺

    横跨中原、江淮、长江天堑、江南运河，含**千古师生相会**人文高光点位。
