# 路线手写模板 · 空白版

> **用法**：复制本文件，重命名为 `R{编号}_{路线主题}.md`，把 `__待填__` 替换成实际内容
> **铁律**：不会的留 null 或 []，不要编

---

## 路线层

```yaml
route_id: R__              # 例：R00 / R01 / R10
route_title: __待填__       # 6-12字，例：眉山故里·少年成长
route_period: __待填__      # 例：1037-1056
route_age_range: __待填__   # 例：0岁-21岁
route_color: "#__"         # 参考色板
route_position: __待填__    # 一句话定位

route_overview:
  time_range:
    start: __待填__
    end: __待填__
    description: |
      __时间区间描述（2-3行）__

  core_essence: |
    __整体核心评述（150-300字，要有路线在苏轼一生中的角色判断）__

  key_events:
    - title: __事件1标题__
      year: null
      age: null
      content: |
        __事件详情__

    - title: __事件2标题__
      year: __待填或null__
      age: __待填或null__
      content: |
        __事件详情__

    - title: __事件3标题__
      year: null
      age: null
      content: |
        __事件详情__

    - title: __事件4标题__
      year: null
      age: null
      content: |
        __事件详情__

  key_locations_summary: |
    __核心游历地点一句话总括__

  literary_output:
    description: |
      __这条路线产出的诗文整体描述__
    representative_works:
      - title: __作品名__
        category: __诗/词/赋/文__
        note: __简短说明__
        year_estimate: __约xxxx年/某时期__
    style_features: __文风特点__
```
