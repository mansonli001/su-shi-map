# R16_出京知颍州、再迁扬州.md
route_overview:
  # 3.1 路线基础信息
  route_id: R16
  route_title: 出京知颍州、再迁扬州
  route_period: 1091-1093
  route_age_range: 54岁-56岁
  route_color: '#3E5A78'
  route_position: 元祐党争避祸主动出京专线，自汴京外放颍州、继而迁任扬州；穿行淮西古道、颍水流域、洪泽湖古渡，独赏**颍州西湖清幽水色、扬州平山堂千年怀古**，心境疏离朝堂、寄情淮上湖山，开启**淮水田园、颍水闲吟、平山怀古**全新创作谱系，是中年后期避党争、乐闲宦的代表性行旅路线

  # 3.2 时间区间描述
  time_range:
    start: 1091年 苏轼第七次短暂回京后，厌弃元祐朝堂派系倾轧，主动请求外放，自汴京启程赴任颍州知州
    end: 1093年 颍州任满，循淮河、洪泽湖古渡水路陆路东行，迁任扬州知州，居扬览胜怀古，安稳闲宦度日
    description: |
      元祐六年（1091）苏轼短暂滞留汴京，看透新旧党无休止内耗，不愿深陷朝堂漩涡，
      决意再度自请外放，离开京师沿陈州古道南下抵达颍州履职。
      居颍期间流连颍水两岸、泛舟颍州西湖，远离朝堂烦扰，过闲逸官宦生活；
      元祐八年（1093）奉旨由颍州改迁扬州，沿颍水入淮河，经洪泽湖古渡一路东行抵达扬州，
      登临平山堂追怀欧公遗韵，览淮左名都风物，
      全程以避祸自守、寄情淮湖山水为主，无朝堂功利之心，只剩湖山闲吟与古今怀古之怀。

  # 3.3 整体核心评述
  core_essence: |
    相比此前杭州西湖的盛大繁华、运河北返的离愁怅惘，
    本条路线主打**避党争、远朝堂、居淮上、乐闲宦**的淡然底色。
    既没有少年赴任的意气，也没有贬谪时期的沉郁，更没有元祐入阁的庙堂荣光，
    纯粹是中年看透党争乱象，主动抽身远离政治中心，择淮上州郡安身度日。
    行路之上，陈州古道平野旷远、颍水蜿蜒清和、洪泽湖古渡烟水苍茫，
    风光介于中原平野与江南水乡之间，清雅内敛、不事张扬；
    驻留之时，颍州西湖清幽静美、不输钱塘却更显恬淡，
    扬州平山堂承欧公文脉，怀古寄怀、追慕前贤风骨。
    文风跳出西湖明艳、朝堂典制、山海仙逸，
    转为**颍水闲淡、淮上清和、平山怀古冲淡**，
    心境与世无争、行事随遇而安，是苏轼中年后期明哲保身、寄情浅山静水的人生写照。
